# src/celestialflow/persist/util_render.py

> 📅 最終更新日: 2026/10/09

`util_render.py`（旧 `graph/util_render.py`、`persist` に移行済み）は、**グラフ構造のレンダリングツール**を提供します。現在は `render_structure_list` という関数のみを含み、グラフ構造（ノード、隣接リスト、ソースノード）を**枠付きのツリー型テキストリスト**にレンダリングします。タスクグラフの起動時に図構造の概要を出力するためにログモジュールが使用します。

## render_structure_list

```python
def render_structure_list(
    nodes: list[str],
    edges: dict[str, list[str]],
    source_nodes: list[str],
) -> list[str]:
```

グラフ構造（ノードのメタ情報、隣接リスト、ソースノード）から枠付きのツリー型テキストリストを生成します。

### レンダリングルール

1. `source_nodes` をルートとして、`edges` の隣接リストに従ってツリー型テキストに展開します；
2. 環や共有サブグラフのノードは一度だけ展開され、再度出現した場合には `[Ref]` とマークされます；
3. どのルートからもレンダリングされなかったノード（孤立ノード）は末尾に追加されます；
4. ルートノードには接続記号を描画せず、子ノードには `╞-->` / `╘-->` の接続記号を使用します。

### 境界処理

- ノードがない場合（空の `nodes`）は `["+ No nodes defined +"]` を返します；
- ソースノードが明示的に提供されていない場合、任意の辺の子ノードでもないノードとして推定します；それでも空の場合は、先頭のノードをソースとします。

### 戻り値の形式

返される文字列リストの先頭と末尾にはそれぞれ 1 本の枠線があり、中央が行ごとの内容です。例：

```text
+----------------------+
| A                    |
| ╞--> B               |
|     ╘--> C [Ref]     |
| ╘--> D               |
+----------------------+
```

行内の内容は `ljust` で同一幅に揃えられ、枠の位置が揃うように保証されます。

## 内部実装の要点

- **明示的なスタック反復による DFS の先行順走査**：深いチェーングラフで Python の再帰上限（デフォルト約 1000 層）がトリガーされるのを回避します。
- スタックフレームは `(node_name, prefix, is_last, is_root)` を保持します。`is_root` はルートノードを示し、ルートノードには接続記号を描画せず、その子ノードのプレフィックスは空です。それ以外のノードのプレフィックスは、親ノードが同層の最後の項目かどうかで決まります。
- 各ノードは初回アクセス時に `expanded_nodes` に追加されます。以降に再度遭遇した場合は `[Ref]` とマークされ、それ以上展開されません。
- ルートノード間、および末尾に追加される孤立ノードの前には、それぞれ空行が 1 行挿入されます。

## 使用例

```python
from celestialflow.persist.util_render import render_structure_list

lines = render_structure_list(
    nodes=["A", "B", "C"],
    edges={"A": ["B", "C"]},
    source_nodes=["A"],
)
for line in lines:
    print(line)
```

## 呼び出し元

`LogInlet`（`persist/core_log.py`）は `on_graph_start` で本関数を呼び出し、`GraphStartEvent` が保持するグラフメタ情報（`nodes` / `edges` / `source_nodes`）を構造テキストにレンダリングして行ごとにログへ書き込みます。

## 注意事項

1. **純粋なメモリレンダリング**：関数はディスクへ書き込まず、実行時間状態にも依存せず、渡されたグラフ構造パラメータに基づいてのみテキストを生成します。
2. **移行の説明**：本ツールは元々 `graph` モジュールの `util_render.py` にありましたが、現在は `persist` に移行され、ログモジュールが再利用します。
3. **テキストリストを返す**：呼び出し側は返された文字列リストをどのように消費するか（行ごとにプリントしたりファイルに書き込んだり）を自分で決める必要があります。
