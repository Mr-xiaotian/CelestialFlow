# フォーマットユーティリティテスト (test_format.py)

> 📅 最終更新日: 2026/08/12

## 役割
`celestialflow.runtime.util_format` の `format_repr` と `format_table` の2つのフォーマット関数を検証し、文字列の短縮表現とテーブルレンダリング出力の正確性を確認します。

## コアテスト対象
- `format_repr`: 長い文字列を「先頭 2/3 + ... + 末尾 1/3」ルールで切り詰め、特殊文字をエスケープします。
- `format_table`: 2次元データを枠線付き ASCII テーブルにレンダリングし、カスタムの行/列名、埋め値、配置をサポートします。

## テストカバレッジマトリクス

| テストクラス | ケース数 | カバレッジ目標 |
|--------|--------|---------|
| `TestUtilFormat` | 9 | `format_repr`（切り詰めなし/あり/境界/エスケープ）；`format_table`（空データ/基本/カスタム名/埋め値/配置） |

## 主要テストシナリオ

### `format_repr` — 文字列短縮表現
1. **切り詰めなし**: 短いテキストはそのまま返され、`max_len` を超えない場合は処理されない。
2. **切り詰め**: 長いテキストは先頭 2/3 + `...` + 末尾 1/3 のルールで切り詰められ、合計長は `max_len + 3` を超えない。
3. **境界**: 最小切り詰め長（`max_len=3`）でも先頭と末尾の文字が正しく保持される。
4. **エスケープ**: 特殊文字（`\n`、`\` など）が正しい可視形式にエスケープされる。

### `format_table` — テーブルレンダリング
1. **空データ**: 空リストは `"表格数据为空！"` プロンプトを返す。
2. **基本テーブル**: 2次元データから自動的にインデックス付きテーブルを生成し、列名はデフォルトで A、B、C...
3. **カスタム名**: `row_names` と `column_names` パラメータで行/列ラベルのカスタマイズをサポート。
4. **埋め値**: 行の長さが一致しない場合、不足セルは `fill_value` で埋められる。
5. **配置**: `align="left"` と `align="right"` で列の配置を制御できる。

## 実行方法

```bash
# すべて実行
pytest tests/runtime/test_format.py -v

# format_repr テストのみ
pytest tests/runtime/test_format.py -k "repr" -v

# format_table テストのみ
pytest tests/runtime/test_format.py -k "table" -v
```

## 重要な詳細
- `format_repr` の切り詰めアルゴリズムは、先頭 2/3 文字 + `...` + 末尾 1/3 文字を保持します。
- `format_table` の第1列は `#` 行番号列で固定されており、`row_names` と相互排他です。
- 列の配置は、ヘッダーとデータの内側パディングの方向を制御することで実現されます。

## 注意事項
